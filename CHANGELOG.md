# Charsets: история изменений

Номера версий называет автор; пока их нет, записи идут по датам публикации.
Всё, что ещё не выложено, собирается в разделе «Не опубликовано».

---

## Не опубликовано

**Добавлено**
- **Лицензия MIT** (`LICENSE`) и её ознакомительный перевод на русский
  (`LICENSE_RU.md`). Код и материалы сайта можно использовать, менять
  и распространять, в том числе в коммерческих продуктах; в копиях сохраняется
  текст лицензии.
- **Сторонние компоненты** — `THIRD-PARTY-NOTICES.md`: шрифты, значки, откуда
  взяты таблицы кодировок, как сторонний файл может появиться.
- **Правила для правок** — `CONTRIBUTING.md`: как устроен сайт, как добавить
  кодировку, что проверить перед публикацией, какие чужие файлы можно брать.
- **История изменений** — этот файл.
- **Самопроверка** — `npm run check`, около 13 тысяч проверок: однобайтовые
  кодировки и формы Unicode сходятся туда и обратно, утверждения сайта
  о конкретных байтах верны, каждый знак кодовых страниц есть в шрифте,
  значки на месте. Там же страж внешних адресов: страницы ничего не грузят
  извне — ни с CDN, ни из репозитория набора значков. Запускается и в GitHub
  Actions при каждом пуше в `main` и на каждый pull request.
- Служебные файлы репозитория: `.gitignore`, `.editorconfig`, `.gitattributes`;
  `package.json` с лицензией, автором, адресами сайта и репозитория.
- В README — ссылка на сайт и раздел «Лицензия».

**Изменено**
- **Значки интерфейса** — из набора Klaarheid Icons вместо символов Юникода:
  меню, «Очистить», «Поменять кодировки», «Прогнать обратно», стрелка списка
  кодировок, пояснение у кодировки, кегль, стрелки конвейера, классических
  пар и карточек главной. Файлы лежат в `icons/`, обновляются командой
  `npm run icons:sync`.
- **Шрифты** собраны заново из авторских релизов: иврит и дробная косая —
  из DejaVu Sans, арабица целиком — из Noto Sans Arabic (SIL OFL 1.1).
  Арабский текст в перекодировщике теперь соединяется, как положено.
- **Тексты лицензий шрифтов** — авторские, из тех же релизов, вместо служебных
  файлов пакетов Debian.
- Локальный сервер — `npm run serve` (модуль `http.server` из Python).

**Исправлено**
- **В проекте лежал фрагмент шрифта FreeMono под лицензией GPL-3+** — без
  полного текста лицензии и без исходников, которых GPL требует для изменённой
  копии. Фрагмент удалён; его знаки теперь берутся из шрифтов с разрешительными
  лицензиями.
- **Огласовка U+05BA в Windows-1255** (байт CA). Браузер её показывает,
  а в шрифтах сайта её не было: набор знаков считался на движке со старыми
  таблицами кодировок.

## 1 сентября 2026

**Добавлено**
- **Ширина конвейера в перекодировщике тянется за кромки** любой из трёх секций —
  синхронно и симметрично для всех; двойной щелчок возвращает исходную ширину,
  стрелки на кромке двигают её с клавиатуры. Ширина запоминается в браузере.
- **Кнопка «Очистить»** у исходного текста. Очистка отменяется через Ctrl+Z;
  так же теперь отменяется и «Прогнать обратно».

**Изменено**
- **Интерфейсный текст — не мельче 14 px.** Подписи колонок таблиц растут
  вместе с кеглем таблицы и при кегле по умолчанию тоже выходят 14 px.
- Заголовки секций перекодировщика стоят в одной строке со своими кнопками.

## 26 августа 2026 — первая публикация

**Добавлено**
- **Главная.** Преобразователь: слева в ящик въезжает «Привет», справа выезжает
  «РџСЂРёРІРµС‚» — то же слово, записанное в UTF-8 и прочитанное как
  Windows-1251. Блок «Знакомо?» и карточки разделов.
- **Обозреватель кодировок.** 39 кодировок — DOS, Windows, ISO 8859, КОИ-8,
  Macintosh, UTF-8, UTF-16, UTF-32 и Base64 — в любом сочетании бок о бок.
  Режим «по коду»: что означает одна и та же последовательность байтов
  в каждой кодировке, от 0 до 65 535. Режим «по символу»: какими байтами
  записан один и тот же символ, по всей базовой плоскости Unicode. Таблицы
  не рвутся: незанятые позиции показаны явно. Колонки DEC, HEX и BIN, запись
  кода раздельно или слитно, приглушение строк, где сравнивать нечего,
  перетаскивание столбцов, кегль таблицы. Служебные состояния — значками
  с подсказками, а символы, которые нечем нарисовать в системе зрителя, —
  своим значком вместо квадрата.
- **Перекодировщик.** Текст — байты — текст: записать одной кодировкой,
  прочитать другой и увидеть кракозябры. Классические пары, панель байтов
  с правкой в DEC, HEX и BIN, те же байты в Base64, список символов,
  потерянных при записи. «Поменять кодировки» и «Прогнать обратно» —
  второе восстанавливает испорченный текст.
- **Свои подмножества шрифтов** для всех знаков кодовых страниц.
