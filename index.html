Кодировки символов

Привет
РџСЂРёРІРµС‚

Слово «Привет» записано в UTF-8, а прочитано как Windows-1251 — и превратилось в «РџСЂРёРІРµС‚».

Знакомо?

Байты те же самые. Изменились только правила, по которым их читают. Достаточно открыть файл «не тем» — и осмысленный текст рассыпается.

Кодировка — это договор о том, каким числом записывается каждый символ. Договоров оказалось много: свой у DOS, свой у Windows, свой у Unix, свой почти у каждого языка. Пока текст не покидал одну систему, всё сходилось. Как только файлы пошли между машинами, начались кракозябры.

Здесь этот механизм показан изнутри — не на пальцах, а побайтно.
