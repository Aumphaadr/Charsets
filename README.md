# Charsets

Учебный сайт о кодировках символов. Отвечает на вопрос, почему человечество
не обошлось одной кодировкой на все случаи жизни.

Спецификация — [SPEC.md](SPEC.md). Читать её стоит раньше кода:
там зафиксированы решения и причины, по которым они приняты.

## Запуск

Статика без сборки. Нужен любой http-сервер — из-под `file://`
ES-модули не грузятся.

```
npx sirv-cli . --dev
```

## Что уже работает

**Главная** — `index.html`.

* Преобразователь: слева въезжает «Привет», справа выезжает
  «РџСЂРёРІРµС‚» — то же слово, записанное в UTF-8 и прочитанное
  как Windows-1251.
* Блок «Знакомо?» и карточки разделов.

**Обозреватель кодировок** — `explorer.html`.

* Тридцать девять кодировок: DOS (CP437, 850, 852, 855, 857, 866),
  Windows (1250…1258), ASCII и ISO-8859-1…16, KOI8-R/U, Mac Roman,
  Mac Cyrillic, UTF-8, UTF-16 LE/BE, UTF-32 LE/BE, Base64.
  Список с поиском и группировкой по семействам.
* Два режима сравнения, переключаются вручную:
  * **по коду** — ось последовательность байтов 0..65 535, у каждой
    кодировки свой символ; на двухбайтовом участке видно, как рождаются
    кракозябры;
  * **по символу** — ось кодовая точка, у каждой кодировки свои байты.
* Несколько кодировок бок о бок, порядок столбцов меняется перетаскиванием
  заголовков.
* Колонки DEC / HEX / BIN включаются чекбоксами, CHAR неотключаем.
* Запись кода переключается: `1 0` или `256`, `13 13` или `3341`.
* Приглушение строк, в которых сравнивать нечего.
* Служебные состояния — компактными значками с подсказкой при наведении.
* Регулятор кегля таблицы в шапке, 10…24, по умолчанию 22.
* Догрузка и сворачивание ленты, длительная отрисовка идёт порциями
  с полосой хода и блокировкой контролов.
* Состояние в хеше URL — ссылкой можно поделиться:
  `explorer.html#mode=code&cs=windows-1251,cp866&cols=dec,hex&dim=1&fs=16&rows=256&join=1`

**Перекодировщик** — `convert.html`.

* Конвейер «текст → байты → текст»: записать одной кодировкой, прочитать
  другой и увидеть кракозябры вживую.
* Кнопки классических пар: UTF-8 → Windows-1251, 1251 → 1252, CP866 → 1251,
  KOI8-R → 1251.
* Два разворота в секции «Байты»: «Поменять кодировки» и «Прогнать
  обратно». Второй восстанавливает испорченный текст — кракозябры
  превращаются обратно в оригинал.
* Панель байтов редактируемая — обратная трансляция «числа в текст».
  DEC / HEX / BIN, терпимый разбор разделителей, отчёт о неразобранном.
* Отдельной строкой: сколько символов потерялось при кодировании и какие,
  и те же байты в Base64.

## Чего ещё нет

* Плоскости выше U+FFFF (сейчас лента доходит до конца BMP).
* Многобайтовые кодировки: Shift_JIS, EUC-JP, EUC-KR, GBK, Big5.
  Браузер их знает, но нужна отдельная модель — см. раздел 9 спецификации.

* Пункты бокового меню.


## Устройство

```
favicon.svg        значок «U+», буквы в кривых
index.html         главная
explorer.html      обозреватель
convert.html       перекодировщик
css/tokens.css     палитра
css/style.css
js/charsets.js     модель кодировок за единым интерфейсом
js/tables.js       таблицы, которых нет в браузере (сгенерированы iconv)
js/parts.js        отрисовка символов и служебных значков
js/render.js       сборка строк и заголовка
js/ui.js           список кодировок, перетаскивание, подсказки
js/nav.js          боковое меню и легенда
js/explorer.js     обозреватель: состояние и связывание
js/convert.js      перекодировщик
js/home.js         главная: начинка ящика
js/glyphs.js       проверка, нарисуется ли символ у посетителя
fonts/             два подмножества шрифтов, 23 КБ, см. fonts/README.md
```

Зависимостей нет: почти всё умеет сам браузер. `TextDecoder` знает
легаси-кодировки, обратная таблица получается инверсией прямой,
UTF-8 кодирует `TextEncoder`. Три таблицы пришлось завести своими —
`TextDecoder` подменяет ASCII и ISO-8859-1 на Windows-1252,
а CP850 не поддерживает вовсе. Подробности в разделе 2 спецификации.
