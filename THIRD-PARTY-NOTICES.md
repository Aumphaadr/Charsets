# Сторонние компоненты и их лицензии

Charsets распространяется по лицензии [MIT](LICENSE). Ниже перечислены сторонние
ресурсы, поставляемые вместе с проектом, и условия их использования. Все они
разрешают свободное использование, в том числе в образовательных организациях
и коммерческих продуктах.

## Шрифты

Таблицы и перекодировщик набраны тремя подмножествами шрифтов: из полных шрифтов
оставлены только знаки, которые рисуют кодовые страницы сайта. Какой знак из какого
файла и как файлы собраны — в [fonts/README.md](fonts/README.md).

| Файл | Шрифт | Правообладатель | Лицензия |
|---|---|---|---|
| `fonts/DejaVuSansMono-Charsets.woff2` | DejaVu Sans Mono 2.37 | Bitstream, Inc.; изменения DejaVu — общественное достояние | Bitstream Vera Fonts License — [fonts/DejaVu-LICENSE.txt](fonts/DejaVu-LICENSE.txt) |
| `fonts/DejaVuSans-Charsets.woff2` | DejaVu Sans 2.37 | Bitstream, Inc.; Tavmjong Bah (глифы Arev); изменения DejaVu — общественное достояние | Bitstream Vera Fonts License и Arev Fonts License — [fonts/DejaVu-LICENSE.txt](fonts/DejaVu-LICENSE.txt) |
| `fonts/NotoSansArabic-Charsets.woff2` | Noto Sans Arabic 2.013 | The Noto Project Authors | SIL Open Font License 1.1 — [fonts/NotoSansArabic-OFL.txt](fonts/NotoSansArabic-OFL.txt) |

Тексты лицензий — авторские, из тех же релизов, что и шрифты. Лицензии DejaVu
разрешают изменять шрифт, если в его имени нет слов «Bitstream» и «Vera» (для глифов
Arev — «Arev» и «Tavmjong Bah»); подмножества сохраняют имена DejaVu Sans Mono
и DejaVu Sans, где этих слов нет. У Noto Sans Arabic зарезервированного имени нет.
Строки об авторских правах и лицензии сохранены и внутри самих файлов.

## Данные о кодировках

Таблицы большинства кодировок сайт не хранит: браузер строит их сам по стандарту
WHATWG Encoding (`TextDecoder`). Семь таблиц, которых в браузере нет или которые
он подменяет другой кодировкой, лежат в `js/tables.js`: CP437, CP850, CP852, CP855,
CP857, ISO-8859-1 и ISO-8859-16. Они получены прогоном программы `iconv` из GNU C
Library и записывают соответствия «байт — символ», которые задают сами стандарты
этих кодировок. Ни кода, ни файлов glibc в проекте нет. Таблица ASCII
не заимствована ни откуда: её верхняя половина пуста по определению.

## Библиотеки

Нет. Сайт написан на JavaScript без библиотек: в `package.json` нет ни
`dependencies`, ни `devDependencies`, `npm` только запускает скрипты. Локальный
сервер `npm run serve` — модуль `http.server` из стандартной библиотеки Python;
подмножества шрифтов пересобирает `pyftsubset` из fontTools. Ни то, ни другое
с проектом не распространяется.

## Код, тексты и изображения

Код, подписи, пояснения и значок вкладки созданы для Charsets и распространяются
по лицензии проекта (MIT). Код и подписи написаны с Claude — ИИ-ассистентом
Anthropic — по методике и под руководством автора.

Значок вкладки `favicon.svg`: надпись «U+» набрана шрифтом DejaVu Sans Mono Bold
и переведена в кривые, так что это рисунок, а не файл шрифта; `favicon.ico`,
`favicon-32.png` и `apple-touch-icon.png` сделаны из него же.

## Если здесь что-то появится

Сторонний файл добавляется только вместе со своей лицензией и строкой в этот
файл: что это, откуда, кто автор, какая лицензия и где файл лежит. Порядок —
в [CONTRIBUTING.md](CONTRIBUTING.md#чужие-файлы).
