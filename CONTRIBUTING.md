# Правки и новые кодировки

Самый полезный вклад в Charsets — сообщение об ошибке: неверный символ в таблице,
байты, которые не сходятся с тем, что выдаёт другая программа, кнопка, которая
ведёт себя не так. [Заведите issue](https://github.com/Aumphaadr/Charsets/issues/new):
на какой странице, какие кодировки и байты, что сделали, что увидели и что
ожидали увидеть.

Правки принимаются на условиях лицензии проекта — [MIT](LICENSE).

## Как устроен сайт

Три страницы: главная `index.html`, обозреватель `explorer.html`
и перекодировщик `convert.html`. Общего у них — шапка, боковое меню
(`js/nav.js`), палитра (`css/tokens.css`) и значки.

- **Модель** — `js/charsets.js`: все кодировки за одним интерфейсом
  (`atBytes`, `encode`, `encodeText`, `decodeText`), без DOM. Её проверяет
  `tools/check.mjs`.
- **Таблицы, которых нет в браузере**, — `js/tables.js`. Остальные строит
  `TextDecoder` браузера, данных для них в репозитории нет.
- **Отрисовка** — `js/render.js` и `js/parts.js`, виджеты — `js/ui.js`,
  страницы — `js/explorer.js`, `js/convert.js`, `js/home.js`.
- **Подробное устройство и принятые решения** — в [SPEC.md](SPEC.md).

## Новая кодировка

1. Строка в списке `CHARSETS` в `js/charsets.js`. Если браузер кодировку знает,
   таблица строится из `TextDecoder` сама; если нет или он её подменяет —
   верхняя половина таблицы в `js/tables.js`, полученная из `iconv`,
   и строка о ней в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
2. `npm run fonts:set` — не прибавилось ли знаков, которых нет в шрифтах.
   Если прибавилось, `npm run check` покажет какие; подмножества пересобираются
   по [fonts/README.md](fonts/README.md).
3. Якорь в `tools/check.mjs`, если о новой кодировке где-то на сайте сказано
   что-то конкретное: какой символ на каком байте.
4. Раздел в [README.md](README.md) и строка в [CHANGELOG.md](CHANGELOG.md)
   в разделе «Не опубликовано».

## Проверка перед публикацией

- `npm run check` проходит без строк «ПРОВАЛ». Нужен Node 24.13.1 или новее:
  у более ранних версий таблицы кодировок расходятся с браузерными, и проверка
  скажет об этом сама.
- Страницы открыты через http-сервер (`npm run serve`), а не с диска:
  из-под `file://` ES-модули не грузятся.
- Каждая правка проверена на широком экране и на ширине телефона, около 400 px.
- В консоли браузера нет ошибок.

## Правила

- **Статика без сборки и зависимостей.** JavaScript в ES-модулях, CSS и SVG,
  без библиотек и без CDN: всё, что нужно странице, лежит в репозитории.
- **Таблицы не врут.** Что сайт утверждает о символах и байтах, считает модель;
  конкретные утверждения из подписей и примеров сверяет `tools/check.mjs`.
- **Таблицы не рвутся.** Незанятая позиция кодировки занимает свою строку
  и показывает отсутствие символа явно, а не сворачивается.
- **Интерфейсный текст — не мельче 14 px**: размеры берутся из токена
  `--fs-ui`. Содержимое таблиц сюда не относится, его кегль выбирает
  пользователь.

## Чужие файлы

Всё, что не создано для проекта, — шрифт, картинка, звук, библиотека, набор
данных — добавляется, только если:

1. лицензия разрешает свободное использование, в том числе в образовательных
   организациях и коммерческих продуктах;
2. текст лицензии лежит рядом с файлом — для шрифта это `Имя-OFL.txt` или
   `Имя-LICENSE.txt` в той же папке;
3. в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) появилась строка: что это,
   откуда, кто автор, какая лицензия и где файл лежит.

Шрифты подключаются своими файлами из репозитория, не с чужих серверов.
Берутся из авторских релизов, а не из пакетов дистрибутивов, и только
с разрешительными лицензиями: копилефт вроде GPL сюда не подходит, даже
с исключением для шрифтов.

Значки берутся из набора [Klaarheid Icons](https://aumphaadr.github.io/Klaarheid-Icons/)
(MIT-0) — копиями файлов в `icons/`, а не ссылками на репозиторий набора.
Добавить значок: правило в `css/style.css` и
`npm run icons:sync -- <путь к локальной копии Klaarheid-Icons> <имя>`.
Синхронизация копирует файлы из `svg/fill` байт в байт и пересобирает раздел
«Значки» в THIRD-PARTY-NOTICES.md.
